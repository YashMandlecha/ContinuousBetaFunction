# Fit4 plot browser

This Streamlit app is adapted from the original gradient-flow plot browser in
`/Users/yaman/Contbetafn/src/betafn/plot_browser`. It keeps fit4 separate because
fit4 is the analysis family with selectable coefficient-prior widths.

The browser discovers result folders dynamically. Paste any completed folders
next to `app.py`, preserving the runner's internal structure:

```text
plot_browser/
  app.py
  fit4_nopriors/
    order_3/t_4_5/...
  fit4_width1000/
    order_3/t_4_5/...
```

Other `fit4_width*` folders are detected automatically. Orders and flow-time
windows also come from the folder contents, so orders 3--6 and the script's
current windows require no hard-coded browser update.

The main tab replaces the legacy finite-volume analysis display with the
infinite-volume continuum-extrapolation plots generated by the notebooks and
batch runner:

- `continuum_a2_over_t_beta_fit4`
- `continuum_a2_over_t_beta_over_g4_fit4`

The second tab exposes the final continuum curves, interpolation diagnostics,
weak-coupling diagnostics, and quality plots from the same selected run.

Install and run with:

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

For convenience during development, the app also detects fit4 folders in the
parent directory. A folder pasted beside `app.py` takes precedence.
